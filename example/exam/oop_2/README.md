# Завдання для ООП (Об'єктно-орієнтоване програмування)

## Загальна структура та вимоги завдання
- завдання виконується у окремій папці, яка є вашим проектом
- ініціалізується проект за допомогою **pipenv** або **poetry** (на ваш вибір)
- у проект встановлюються бібліотеки для роботи з AI (`google-adk`, `python-dotenv` та інші, які ви вважаєте за потрібне)
- створюється файл `README.md` де вказується номер варіанту та завдання
- активовується проект та створюється AI агент за допомогою засобів Google ADK
- **ЗАГАЛЬНЕ ЗАВДАННЯ:**
    * у файлі `agent.py` реалізувати OOP-класи, що демонструють **усі 4 парадигми ООП** (інкапсуляція, наслідування, поліморфізм, абстракція)
    * модифікувати промпт для AI агента згідно з варіантом завдання
    * створити інструмент (функцію `tool`), який буде використовувати AI агент згідно з варіантом завдання
- запустити проект та продемонструвати роботу AI агента, вивести результат
- якщо код працює коректно, завдання вважається виконаним

---
## Загальні вимоги до здачі

1. Проект знаходиться у окремій папці (наприклад `exam_variant_1/`)
2. Проект ініціалізований за допомогою `pipenv` або `poetry`
3. Встановлено залежності: `google-adk`, `python-dotenv`
4. Наявний файл `.gitignore` (ігноруються `.env`, папки середовища)
5. Наявний файл `README.md` з номером варіанту та описом завдання
6. Файл `agent.py` містить:
   - OOP-класи (всі 4 парадигми)
   - функцію-інструмент (tool)
   - визначення `root_agent`
7. Проект запускається командою `adk run` або `adk web`
8. У звіті наявний скріншот або лог роботи агента (мінімум 3 діалоги)
---
> **Критерії оцінювання:**
> - Коректна ініціалізація проекту з менеджером пакетів (pipenv або poetry)
> - Наявність `.gitignore` з ігноруванням файлів середовища та `.env`
> - Реалізація всіх 4 парадигм ООП у коді
> - Коректно визначений та підключений інструмент (tool) для агента
> - Змістовний промпт агента відповідно до варіанту
> - Демонстрація роботи агента (скріншот або лог діалогу у звіті)

## Варіант 1 — Агент прогнозу погоди

### OOP-завдання
Реалізуйте ієрархію класів для метеостанції:

1. Абстрактний клас `Sensor` (модуль `abc`) з абстрактним методом `read()` та атрибутами `name` і `unit`.
2. Класи `TemperatureSensor` та `HumiditySensor`, що успадковують `Sensor` та реалізують метод `read()` — повертають відповідне числове значення (температура в °C, вологість у %). Значення можна задати через `random`.
3. Клас `WeatherStation` що:
   - приймає `city: str` у конструкторі
   - зберігає список датчиків (`__sensors` — приватний атрибут, інкапсуляція)
   - має метод `add_sensor(sensor)` та метод `report() -> dict` — повертає словник `{"city": ..., "temperature_c": ..., "humidity_percent": ..., "condition": ...}` зібраний з показників датчиків (поліморфізм через виклик `read()` кожного датчика)

### AI-агент
- **Інструмент (tool):** функція `get_weather(city: str) -> dict` — **всередині функції** створює об'єкт `WeatherStation(city)`, додає до нього `TemperatureSensor` та `HumiditySensor`, викликає метод `report()` та повертає результат.
- **Промпт агента:** агент є метеорологічним помічником. Він повідомляє про поточну погоду в містах та дає рекомендації (що вдягнути, чи брати парасолю тощо). Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 запитання про погоду в різних містах.

## Варіант 2 — Агент розрахунку геометричних фігур

### OOP-завдання
Реалізуйте ієрархію геометричних фігур:

1. Абстрактний клас `Shape` з абстрактними методами `area()` та `perimeter()`.
2. Класи `Rectangle`, `Triangle`, `Circle` що успадковують `Shape` та реалізують обидва методи.
3. Клас `ShapeStorage` що:
   - зберігає список фігур (`__shapes` — приватний атрибут, інкапсуляція)
   - має методи `add(shape)` та `total_area()` — повертає суму площ усіх фігур (поліморфізм)

### AI-агент
- **Інструмент (tool):** функція `calculate_shape_area(shape: str, params: dict) -> dict` — приймає назву фігури (`"rectangle"`, `"triangle"`, `"circle"`) та словник з параметрами (наприклад, `{"width": 5, "height": 3}`). **Всередині функції** на основі `shape` створюється відповідний об'єкт (`Rectangle`, `Triangle` або `Circle`) з переданими параметрами, після чого викликаються методи `area()` та `perimeter()`. Повертає `{"shape": ..., "area": ..., "perimeter": ...}`.
- **Промпт агента:** агент є математичним асистентом з геометрії. Він обчислює площі та периметри фігур за введеними розмірами та пояснює формули. Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 задачі з геометрії (різні фігури та розміри).

## Варіант 3 — Агент управління магазином

### OOP-завдання
Реалізуйте систему товарів магазину:

1. Абстрактний клас `Product` з атрибутами `name`, `price: float`, `quantity: int` та абстрактним методом `get_info() -> dict`.
2. Класи `Electronics` та `FoodItem` що успадковують `Product` та реалізують `get_info()` — повертають словник з інформацією про товар у різному форматі (наприклад, `Electronics` додає поле `"warranty_years"`, а `FoodItem` — `"expiry_days"`).
3. Клас `Store` що:
   - зберігає товари у приватному словнику `__inventory: dict[str, Product]` (інкапсуляція)
   - має методи `add_product(product)`, `find(name: str) -> Product | None` та `list_products()` (поліморфізм через `get_info()`)

### AI-агент
- **Інструмент (tool):** функція `get_product_price(product_name: str) -> dict` — **всередині функції** створює об'єкт `Store`, додає кілька заздалегідь визначених товарів (`Electronics`, `FoodItem`), викликає `find(product_name)`, отримує інформацію через `get_info()` та повертає її. Якщо товар не знайдено — повертає `{"available": False}`.
- **Промпт агента:** агент є консультантом інтернет-магазину. Він повідомляє ціни на товари, наявність та деталі (гарантія, термін придатності). Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 запитання про різні товари.

## Варіант 4 — Агент успішності студентів

### OOP-завдання
Реалізуйте систему обліку успішності:

1. Абстрактний клас `Person` з атрибутами `name`, `age` та абстрактним методом `get_role() -> str`.
2. Клас `Student` що успадковує `Person`:
   - зберігає оцінки у приватному списку `__grades` (інкапсуляція)
   - методи `add_grade(grade: float)`, `average() -> float`, `min_grade() -> float`, `max_grade() -> float`, `get_role()`
3. Клас `Teacher` що успадковує `Person`:
   - атрибут `subject`
   - методи `get_role()` та `evaluate(student: Student, grade: float)` — додає оцінку студенту через `student.add_grade()`

### AI-агент
- **Інструмент (tool):** функція `calculate_grade(name: str, scores: list) -> dict` — **всередині функції** створює об'єкт `Student(name, age=18)`, додає кожну оцінку зі списку через `add_grade()`, після чого викликає `average()`, `min_grade()`, `max_grade()` для формування відповіді. `letter_grade` визначається за шкалою: 90+ → A, 75+ → B, 60+ → C, нижче → F. Повертає `{"student": ..., "average": ..., "min": ..., "max": ..., "letter_grade": ...}`.
- **Промпт агента:** агент є освітнім асистентом. Він розраховує середній бал, визначає рейтинг та дає поради щодо покращення успішності. Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 запитання з іменами студентів та різними наборами оцінок.

## Варіант 5 — Агент конвертації валют

### OOP-завдання
Реалізуйте систему фінансових активів:

1. Абстрактний клас `Asset` з атрибутами `name`, `amount` та абстрактним методом `get_value_uah() -> float`.
2. Клас `CurrencyAsset` що успадковує `Asset`:
   - приватний атрибут `__rate_to_uah` (інкапсуляція)
   - властивість-геттер `rate` та метод `get_value_uah()` — повертає `self.amount * self.__rate_to_uah`
3. Клас `CryptoAsset` що успадковує `Asset`:
   - власна логіка `get_value_uah()` з волатильністю: базовий курс + `randint(-500, 500)`
4. Клас `Portfolio` що:
   - зберігає список активів (`__assets` — приватний, інкапсуляція)
   - методи `add(asset)` та `total_value_uah()` — сума вартості всіх активів (поліморфізм через `get_value_uah()`)

### AI-агент
- **Інструмент (tool):** функція `convert_currency(amount: float, from_currency: str, to_currency: str) -> dict` — **всередині функції** на основі фіксованих курсів до UAH (USD → 41.5, EUR → 45.0, GBP → 52.0, BTC → 3_800_000) створює об'єкт `CurrencyAsset(from_currency, amount, rate_to_uah)`, викликає `get_value_uah()` щоб отримати суму в UAH, потім ділить на курс цільової валюти. Повертає `{"from": ..., "to": ..., "amount": ..., "result": ..., "rate": ...}`.
- **Промпт агента:** агент є фінансовим консультантом з обміну валют. Він конвертує суми між валютами та пояснює поточний курс. Відповідає **українською мовою**.
- **Демонстрація:** поставте агенту 3 запитання з конвертації різних валют.
