# Робота з ООП
> Ноутбук [classes.ipynb](classes.ipynb) крок за кроком показує всі основні конструкції класів Python на прикладі класу `MyAnimals`.

## Мета роботи
Навчитись працювати з класами та їх основними конструкціями: атрибути, методи, змінні класу, статичні методи, властивості, методи класу, приватні атрибути та магічні методи.

## Що потрібно знати / підготувати
- виконана робота [«Знайомство з ООП»](../05_OOP_first_class/README.md);
- Python 3.13+ та розширення `Jupyter` для VS Code;
- скопіюйте [classes.ipynb](classes.ipynb) у папку своєї роботи (оригінал не змінюйте);

---
## Хід роботи
1. Відкрийте свою копію `classes.ipynb`, виконайте комірки **по порядку** (кожна наступна комірка залежить від попередніх);
1. Після кожного блоку є markdown-завдання. :star: Для кожного завдання створіть **нову** кодову комірку під прикладом, виконайте його та додайте короткий коментар (1-2 речення) про те, що ви побачили.

### Завдання по блоках ноутбука
| № | Блок | Що потрібно зробити |
| --- | --- | --- |
| 1 | Базовий клас | вивести тип створеного об'єкта (`type(a)`) |
| 2 | Порівняння простих даних з об'єктами | перейменувати об'єкти `a1`–`a3` та вивести їх |
| 3 | Методи класу | застосувати методи `speak` та `add_one_year` до всіх об'єктів `a1`–`a3` |
| 4 | Змінні класу | створити кілька об'єктів у циклі та вивести змінну класу |
| 5 | Статичні методи та `self` | викликати статичний метод для кожного об'єкта |
| 6 | Властивості (`property`) | додати ще одну властивість і вивести її |
| 7 | Методи класу (`classmethod`) | дописати перевірку, що `name` починається з великої літери; перетворити `age` на `int` у `from_csv` |
| 8 | Приватні атрибути | пояснити різницю між `_attr` та `__attr` (name mangling) |
| 9 | Магічні методи | додати `__eq__` для порівняння тварин за ім'ям та віком |
| 10 | Арифметичні методи | додати `__add__`; зрозуміти, чому в ноутбуці повертається `NotImplemented` |

### Додаткові завдання
- :fire: Створіть клас `Zoo`, що зберігає список `MyAnimals`, реалізує `__len__`, `__iter__` та `__getitem__`;
- :fire: Перенесіть клас `MyAnimals` у файл `animals.py`, імпортуйте його в ноутбук та протестуйте двома `assert`.

> [!WARNING]
> Якщо в одній комірці клас перевизначено, об'єкти, створені раніше, залишаються екземплярами **старого** класу. Після змін класу заново створюйте об'єкти.

## Контрольні питання
1. Чим `@property` відрізняється від звичайного методу?
1. Що відбувається, коли значення змінної класу присвоюється через об'єкт (`a1.total_animal_types = ...`)?
1. Чому `__secret` недоступний ззовні за іменем, але доступний як `_MyAnimals__secret`?
1. Навіщо повертати `NotImplemented` у `__sub__`, а не піднімати помилку?
