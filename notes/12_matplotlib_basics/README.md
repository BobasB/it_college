# Візуалізація результатів з `matplotlib`
> `matplotlib` — основна бібліотека Python для побудови графіків. Вона тісно працює з `NumPy`, а візуалізація допомагає зрозуміти дані краще, ніж таблиці чисел.

## Мета роботи
Навчитись будувати лінійні графіки, діаграми розсіювання (`scatter`), гістограми та стовпчикові діаграми, підписувати осі, додавати легенду й зберігати графіки у файл.

## Що потрібно знати / підготувати
- виконана робота [«NumPy, вступ»](../11_numpy_basics/README.md);
- бібліотеки `matplotlib` та `numpy` (в ноутбуці є комірка `%pip install matplotlib`; або `pip install matplotlib numpy`);
- у ноутбуці для відображення графіків має бути `%matplotlib inline`;
- ноутбук: [1_matplotlib.ipynb](./1_matplotlib.ipynb) — скопіюйте його у папку своєї роботи;

## Хід роботи
1. Відкрийте ноутбук та виконайте комірки по порядку. Після першої комірки може знадобитись перезапуск ядра (`Restart`);
1. Розберіть, як працюють:
    - `plt.plot` — лінійний графік (значення `x` береться з номера елемента);
    - `plt.scatter` — точки (кількість елементів `x` та `y` має збігатись);
    - `plt.hist` та `np.histogram` — розподіл значень;
    - `plt.xlabel`, `plt.ylabel`, `plt.title`, `label=` + `plt.legend()` — підписи;
1. :star: Для кожного графіка ноутбука напишіть у Markdown-комірці 1-2 речення: що показує графік;

### Завдання
1. :star: У комірці з декількома функціями (`ya`, `yb`, `yc`, `yd`) додайте виклик `plt.legend()`, щоб відобразити підписи (`label=`), та `plt.grid(True)`. Знайдіть візуально точки перетину прямих `y = (5 - x)/4` та `y = 2 - x`, перевірте результат обчисленням;
1. :star: Побудуйте на одному полотні `sin(x)` та `cos(x)` для `x` від `0` до `2π` (`np.linspace`), з різними стилями ліній (`"-"`, `"--"`), легендою та заголовком;
1. :star: Побудуйте стовпчикову діаграму (`plt.bar`) для кількості унікальних значень у масиві `x` із ноутбука (`np.unique(x, return_counts=True)`);
1. :star: Побудуйте 2 графіки поруч за допомогою `fig, axes = plt.subplots(1, 2, figsize=(10, 4))`: гістограму `y` (`bins=20`) та `scatter(x, y)`;
1. :star: Збережіть один із графіків у файл `plot.png` через `plt.savefig("plot.png", dpi=150)` (виклик **до** `plt.show()`) і додайте картинку у звіт;
1. :fire: Побудуйте графік функції власного варіанту (наприклад, `y = x² − 4x + 3`), позначте на ньому точки мінімуму та нулі функції (`plt.scatter`, `plt.annotate`);
1. :fire: Візуалізуйте результати з роботи про [лінійне програмування](../13_linear_programming/README.md): область допустимих розв'язків для двох обмежень.

> [!WARNING]
> Якщо графік не відображається у ноутбуці — перевірте, що виконано `%matplotlib inline`, а після зміни коду заново запустіть комірку з `plt.show()`. Якщо імпорт `matplotlib` завершується помилкою — бібліотека не встановлена в тому середовищі, яке вибрано як ядро (`Select Kernel`).
