# Оформлення та здача робіт
> **Тема**: загальні правила оформлення звітів, перша програма на Python та Jupyter Notebook.

## Мета роботи
Налаштувати VS Code для роботи з Python, написати першу програму у файлі `.py` та в ноутбуці `.ipynb`, оформити звіт у Markdown і здати роботу через Google Classroom.

## Що потрібно знати / підготувати
- виконані роботи [«Налаштування середовища»](../01_first_lesson/README.md) та [«GitHub і Markdown»](../02_github_repository/README.md);
- клонований репозиторій відкрито у VS Code;

## Загальні правила оформлення робіт
- [Шаблон звіту](../../reports/README.md) та [приклад зданої роботи](https://github.com/BobasB/it_college/tree/main/reports);
- для кожної роботи створюйте окрему папку в корені репозиторію з назвою **лише латиницею**, без пробілів, наприклад `lab_03_first_program`;
- скопіюйте шаблон звіту `README.md` у цю папку та поступово заповнюйте його під час виконання роботи;
- скріншоти зберігайте поруч у папці `pictures/` і підключайте **локальними** шляхами (`![опис](./pictures/screen1.png)`);
- не комітьте службові файли: `.venv/`, `__pycache__/`, `.env` — для них є `.gitignore`;
- звіт має бути самостійним: код, вивід програми та пояснення повинні бути видимими без запуску вашого комп'ютера.

## Хід роботи

### 1. Розширення VS Code
1. Відкрийте вкладку `Extensions` на лівій панелі;
1. Встановіть `Python` (разом із ним встановиться `Jupyter` та `Pylance`; якщо ні — додайте вручну);
1. Встановіть `GitHub Copilot` та `GitHub Copilot Chat`, увійдіть у GitHub-акаунт;
1. Перезавантажте VS Code. Переконайтесь, що Python-код підсвічується, а Copilot дає підказки.

### 2. Перша програма на Python
1. Створіть папку роботи та файл `my_first_app.py` з кодом:
    ```python
    from datetime import datetime

    name = "Bohdan"
    location = "Lviv"

    print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
    ```
1. Змініть `name` на своє ім'я, а `location` — на улюблене місто;
1. Запустіть програму: кнопка `Run Python File` (:arrow_forward:) **та** командою в терміналі:
    ```bash
    python my_first_app.py
    ```
1. :star: Вкажіть у звіті, що вивела програма (текст або скріншот).

> [!WARNING]
> Якщо запуск у терміналі повертає `python: command not found`, спробуйте `python3 my_first_app.py` та перегляньте розділ про `PATH` у [першій роботі](../01_first_lesson/README.md).

### 3. Jupyter Notebook
1. Створіть файл `my_first_app.ipynb` — він ділиться на комірки;
1. Скопіюйте код з попереднього пункту у першу комірку та виконайте її (`Execute Cell` або `Shift+Enter`). Якщо VS Code запитає інтерпретатор Python, оберіть встановлений Python 3.13+;

    > [!TIP]
    > Якщо з'явиться запит встановити `ipykernel` — погодьтесь і зачекайте завершення встановлення.

1. Додайте комірку типу `Markdown` з описом («Моя перша програма»), оформіть його як заголовок (`# Моя перша програма`) та виконайте комірку;
1. :star: Вкажіть у звіті результат (скріншот ноутбука з виконаними комірками);
1. Запитайте в AI/Copilot, яку першу програму він би написав, і додайте відповідь у ноутбук (код — у кодовій комірці, пояснення — у Markdown-комірці). Запустіть її та переконайтесь, що вона працює.

### 4. Завантаження роботи у репозиторій
1. Збережіть усі файли (включно зі скріншотами);
1. На вкладці `Source Control` додайте зміни, напишіть повідомлення коміту та натисніть `Commit`, потім `Sync Changes`;
1. Відкрийте репозиторій у браузері та переконайтесь, що всі файли відображаються правильно.

## Що має бути у звіті
- результат запуску `my_first_app.py` (двома способами);
- скріншот ноутбука з кодовою та Markdown-комірками;
- програма від AI та оцінка того, чи вона працює;
- висновок за шаблоном.

## Критерії оцінювання
| Рівень | Що потрібно виконати |
| --- | --- |
| Достатній | `.py` і `.ipynb` створені, програми запускаються, звіт містить результати |
| Високий | + звіт оформлено за шаблоном зі скріншотами та локальними шляхами, є змістовні коміти |
| Відмінний | + порівняно власну програму та програму від AI, описано відмінності та проблеми, які виникли |
