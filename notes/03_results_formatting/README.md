# Оформлення та здача робіт
> **Тема**: Вступні заняття: налаштування середовища, початок роботи з Python та Markdown.
---
> **Мета**: налаштувати середовище роботи у VS Code, створити репозиторій GitHub та налаштувати інтеграцію з ним, написати першу програму на Python і створити звіт із використанням форматування Markdown.

---
### Загальне оформлення робіт
- [Загальний вигляд зданої роботи](https://github.com/BobasB/it_college/tree/main/reports);
- у кореневій папці репозиторію створіть папку з абревіатурою роботи, наприклад `1_lab` або `1_python_program` (назви придумуйте самі, головне, щоб вони містили лише латинські символи);
- для зручності скопіюйте файл `README.md` із шаблоном звіту до новоствореної папки;
- у процесі виконання роботи вносьте зміни до шаблону, поступово його заповнюючи;

---
### Встановлення плагінів VS Code
1. Встановіть додаткові розширення (вкладка `Extensions` на лівій панелі);
    - знайдіть та встановіть розширення `Python`;
    - разом із ним буде встановлено ще декілька розширень, зокрема `Jupyter`, які будуть потрібні для роботи. Якщо вони не встановилися автоматично, додайте їх;
    - знайдіть розширення `Copilot` та встановіть його;
1. після інсталяції всіх розширень перезавантажте VS Code та перевірте, чи працює підсвічування коду Python і чи Copilot дає підказки;

---
### Перша програма на Python
1. організуйте структуру репозиторію та створіть папку, у якій виконуватимете цю роботу. Зберігайте всі файли в цій папці;
1. створіть новий файл із розширенням `.py`, наприклад `my_first_app.py`, та скопіюйте в нього код програми:
    
    ```python
    from datetime import datetime
    name = "Bohdan"
    location = "Lviv"

    print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
    ```

1. змініть значення змінної `name` на своє ім'я, замініть змінну `location` на назву свого улюбленого міста та натисніть кнопку `Run Python File` (трикутник :arrow_forward:), щоб запустити програму;
    - :star: на лекції ми використовували декілька способів запуску програм, спробуйте їх.
1. :star: вкажіть у звіті, що вивела програма, або зробіть скріншот і вставте його у звіт;
1. створіть новий файл із розширенням `.ipynb`, наприклад `my_first_app.ipynb`. Він буде поділений на комірки;
1. скопіюйте код у першу комірку та натисніть кнопку `Run All` угорі або `Execute Cell` ліворуч (трикутник :arrow_forward:). Якщо програма запитає, який інтерпретатор Python використовувати, виберіть його у випадаючому меню;

    > [!TIP]
    > якщо з'явиться вікно з повідомленням про необхідність встановити додаткові бібліотеки Python, погодьтеся та зачекайте, доки їх буде встановлено;

1. :star: вкажіть у звіті, що вивела програма, або зробіть скріншот і вставте його у звіт;
1. Python Notebook дає змогу в інтерактивному режимі працювати з кодом, а також створювати комірки з різними типами форматування. Створіть ще одну комірку з типом `Markdown`. Напишіть опис свого коду, наприклад «Моя перша програма»;
1. натисніть `Run All` та простежте, як змінився вигляд Notebook. Для редагування комірки натисніть `Edit Cell`. Оформіть свій опис у вигляді заголовка;
1. :star: вкажіть у звіті, що вивела програма, або зробіть скріншот і вставте його у звіт;
    - до репозиторію потрібно додати файл ноутбука з виконаними комірками та зафіксувати цю зміну комітом;
1. запитайте в AI/Copilot, яку першу програму він написав би та чи зміг би її пояснити. Додайте цю програму до свого звіту (відповідь AI відформатуйте відповідно до місця вставлення: у комірках Notebook або у файлі README). Використовуйте форматування `Markdown`, щоб оформити комірку з відповіддю AI/Copilot;
    - перевірте, чи запропонована AI програма виконується на вашому комп'ютері, запустивши її.

### Завантаження роботи у репозиторій

1. перевірте у веббраузері, чи всі файли завантажилися та коректно відображаються на платформі GitHub;
