#### 1. Типи помилок та `try`/`except`
Ловіть **конкретні** винятки, а не всі підряд (`except Exception` приховує справжню причину):


#### 2. Робота з файлами
Режими відкриття: `"r"` — читання, `"w"` — запис (**стирає** старий вміст), `"a"` — дописування в кінець. Завжди вказуйте `encoding="utf-8"`, інакше кирилиця на Windows може записатись неправильно:
```python
with open("table.md", "w", encoding="utf-8") as f:
    f.write("| Ім'я | Бал |\n")
    f.write("|------|-----|\n")

for name, mark in [("Іван", 5), ("Марія", 4)]:
    with open("table.md", "a", encoding="utf-8") as f:
        f.write(f"| {name} | {mark} |\n")

with open("table.md", "r", encoding="utf-8") as f:
    print(f.read())

print(f.closed)  # True: файл закрито автоматично при виході з with
```
> [!WARNING]
> Якщо відкрити файл у режимі `"w"` кілька разів без закриття, дані перезапишуть одне одного. Конструкція `with` закриває файл навіть тоді, коли всередині виникла помилка.

#### 3. Формат JSON
`JSON` — текстовий формат для обміну даними (API, налаштування). У Python він відповідає словникам і спискам:
```python
import json

data = {"група": "КН-31", "студенти": [{"ім'я": "Іван", "бал": 5}]}
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=4)

with open("data.json", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded["студенти"][0]["ім'я"], loaded == data)
```

#### 4. Функції, типи та функції як аргументи
Принцип DRY (*Don't Repeat Yourself*): код, що повторюється, виносимо у функцію. Функція — це об'єкт, її можна зберегти у змінну або передати в іншу функцію:
```python
def square_if_positive(x: int) -> int:
    """Повертає квадрат подвоєного числа, якщо воно додатне, інакше 0."""
    return (x * 2) ** 2 if x > 0 else 0


as_lambda = lambda x: (x * 2) ** 2 if x > 0 else 0
print([square_if_positive(x) for x in range(-2, 3)] == [as_lambda(x) for x in range(-2, 3)])


def apply(func, value):
    return func(value)


print(apply(square_if_positive, 3), apply(lambda v: v + 1, 3))
```
Підказки типів (`x: int`, `-> int`) не перевіряються під час виконання, але допомагають редактору та колегам.

#### 5. Декоратори
Декоратор — це функція, яка «обгортає» іншу функцію й додає їй поведінку, не змінюючи її код:
```python
import time
from functools import wraps


def timer(func):
    @wraps(func)  # зберігає ім'я та docstring оригінальної функції
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} виконалась за {time.perf_counter() - start:.6f} с")
        return result
    return wrapper


@timer
def slow_sum(n: int) -> int:
    return sum(range(n))


print(slow_sum(100_000))
```
