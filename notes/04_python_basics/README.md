### Основні конструкції в Python
1. :star: виконайте наведені нижче приклади коду на Python та вставте їх у звіт;
1. :star: якщо важко придумати, з чим попрацювати в кожному завданні (не знаєте, який цикл написати або яку змінну вивести), запитайте в AI/Copilot, який приклад він навів би, та вставте його відповідь у звіт (перед цим правильно її відформатувавши);
1. Створіть файл Python `*.py` або `.ipynb`, у якому виконуватимете базові приклади. За допомогою команди `print` виконайте наступне:
    1. Ознайомтеся з основними [типами даних](https://docs.python.org/3.12/library/stdtypes.html#numeric-types-int-float-complex). Попрактикуйтеся з простими змінними `str` та `int`, списками `list`, наборами `set` і словниками `dict`:
        ```python
        a = "змінна з текстом"
        a1 = 'a'
        b = 1 # числова змінна
        b1 = 1.1 
        c = ["a", 1, 1.25, "Слово", a] # List
        d = {"a": "Слово", "b": 1, a: b} # Dict
        e = ("a", a) # Tuple
        f = {"ss", a, b} # Set (елементи мають бути hashable; a + b дало б TypeError: str + int)
        ```
        :star: Виведіть тип кожної змінної через `type()` і поясніть, чим відрізняються `list`, `tuple`, `set`, `dict`.
    1. Виведіть [вбудовані константи](https://docs.python.org/3.12/library/constants.html) (2–3 на вибір) та [зарезервовані слова Python](https://realpython.com/lessons/reserved-keywords/). Наприклад:
       ```python
       print("Перша константа: ", True)
       print(f"Як можна так робити вивід? {True}")
       help("keywords")
       ```
    1. Виведіть результат роботи [вбудованих функцій](https://docs.python.org/3.12/library/functions.html#func-repr) (2–3 на вибір), наприклад:
       ```python
       print(abs(-12.5), f"є рівним {abs(12.5)}", "і якщо порівняти то: ", abs(-12.5) == abs(12.5))
       ``` 
    1. Ознайомтеся з [циклами](https://docs.python.org/3.12/reference/compound_stmts.html#the-for-statement). Напишіть будь-який код, який демонструє роботу циклів (2–3 на вибір), наприклад:
        ```python
        letters = ["a", "b", "c"]
        for i in range(len(letters)):
            print(f"На позиції {i} знаходиться буква {letters[i]}")
        else:
            print("Блок else виконується, якщо цикл завершився без `break`")
        ```
        :star: Додайте `break` у цикл і перевірте, що блок `else` більше не виконується. Напишіть також цикл `while`.
    1. Ознайомтеся з [розгалуженнями](https://docs.python.org/3.12/reference/compound_stmts.html#the-if-statement). Напишіть будь-який код, який демонструє роботу розгалужень (2–3 на вибір), наприклад:
        ```python
        from random import randint
        A = randint(0, 1)
        print(f"Значить А={A}" if A else "Але може бути що А={}".format(A))
        ```
    1. Конструкція `try` -> `except` -> `finally`. У мові Python код не компілюється, а виконується одразу. Можливі помилки потрібно перехоплювати самостійно. Напишіть власний варіант коду з помилкою. Наприклад:
        ```python
        A = 0
        try:
            print("Що буде якщо", 10/A, "?")
        except Exception as e:
            print("Невже це помилка > ", e)
        finally:
            print("О це так на тобі!")
        ```
    1. Контекстний менеджер `with`. Докладніше можна прочитати [тут](https://python-scripts.com/contextlib). Напишіть власний код із контекстним менеджером, наприклад:
        ```python
        with open("README.md", "r", encoding="utf-8") as f:
            for number, line in enumerate(f):
                print(f"{number})> ", line)
        ```
        > [!WARNING]
        > Файл `README.md` має існувати в папці, звідки запускається програма, інакше буде `FileNotFoundError`. Перехопіть цю помилку за допомогою `try`/`except`.
    1. Ознайомтеся з [лямбда-функціями Python](https://docs.python.org/3.12/reference/expressions.html#lambda). Напишіть власний приклад коду та поясніть, як ви розумієте лямбда-функції, наприклад:
        ```python
        def a_b_func(a, b):
            return a, b

        this_is_lambda = lambda first, age: f'Цей код написав: {first}, Мені {age:10d} років'
        print("Це просто функція:", a_b_func, "\nА це лямбда:", this_is_lambda)
        print("Це її виклик:", this_is_lambda('Богдан', 1_00_000))
        print(this_is_lambda(*a_b_func("a", 1)))
        ```
1. :star: Запитайте в AI, як він описав би основи Python (у запиті вкажіть, що ви вивчаєте Python із використанням Jupyter Notebook). Спробуйте виконати приклади коду Python та вставте їхні результати у звіт;
