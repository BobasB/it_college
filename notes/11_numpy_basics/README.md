# Числові методи в Python: вступ до NumPy
> `NumPy` ("Numerical Python") — основна бібліотека для роботи з масивами, векторами та матрицями. На ній побудовані `pandas`, `matplotlib`, `scikit-learn`.

## Мета роботи
Навчитись створювати та досліджувати масиви `NumPy` (вектори, матриці), генерувати послідовності (`arange`, `linspace`), використовувати індексацію та зрізи, виконувати арифметичні операції над масивами.

## Що потрібно знати / підготувати
- Python 3.13+, розширення `Jupyter` для VS Code;
- бібліотека `numpy` (в ноутбуці є комірка `%pip install numpy`, або `pip install numpy` / `poetry add numpy` у віртуальному середовищі);
- виконана робота про [віртуальні середовища](../06_python_virtualenvs/README.md) (бажано працювати у власному `venv`);

### Самостійні завдання
1. :star: Визначте формули, за якими `arange` та `linspace` генерують значення. Порівняйте їх: для яких випадків підходить кожен метод (підказка: крок vs кількість точок; похибки округлення при дробовому кроці);

1. :star: Порівняйте швидкість множення на 5 для списку Python та `np.array` із 1 000 000 елементів (`%timeit` у комірці ноутбука). Поясніть різницю;
1. :fire: Створіть масив `np.arange(1, 25).reshape(2, 3, 4)` та виведіть: другий «шар», останній стовпець кожної матриці, усі парні числа (булева маска).

> [!WARNING]
> Типова помилка: `temperature * 5` для звичайного списку повторює список 5 разів, а не множить елементи. Для `np.array` множення виконується поелементно.
