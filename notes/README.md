# Список робіт

Кожна робота описана у власній папці та має однакову структуру: **мета → що потрібно знати → хід роботи → що додати у звіт → критерії оцінювання → контрольні питання → здача**.
Позначки в завданнях: :star: — обов'язково вказати у звіті, :fire: — завдання підвищеної складності, :warning: — типова помилка.

Загальні правила оформлення та здачі: [03_results_formatting](./03_results_formatting/README.md). Шаблон звіту: [reports/README.md](../reports/README.md). Шаблон для створення нових робіт: [LAB_TEMPLATE.md](./LAB_TEMPLATE.md).
